Storage and Retrieval. On the most fundamental level, a database needs to do two things: when you give it some data, it should store the data, and when you ask it again later, it should give the data back to you. In Chapter 2 we discussed data models and query languages — the format in which you (the application developer) give the database your data, and the mechanism by which you can ask for it again later. In this chapter we discuss the same from the database's point of view: how we can store the data that we're given, and how we can find it again when we're asked for it. Why should you, as an application developer, care how the database handles storage and retrieval internally? You're probably not going to implement your own storage engine from scratch, but you do need to select a storage engine that is appropriate for your application, from the many that are available…

Memory layers bill on what they extract, so that gap is roughly the cost gap too. All the chunking and every model call happen on your machine and are free — in distil mode a 200,000-character document costs the same at the provider as a 2,000-character one.

Install

Four steps, about two minutes.

It is not in the Chrome Web Store yet, so it loads unpacked. You need Node and a Chrome that has WebGPU.

Clone it and build

git clone https://github.com/anonalabs/magpie && cd magpie

npm install && npm run vendor:wasm && npm run build

Load it into Chrome

Open chrome://extensions, turn on Developer mode, choose Load unpacked and pick the dist/ folder.

Point it at your memory layer

Open the popup, pick Anona Memory, Mem0 or Supermemory, and paste an API key. Your spaces load themselves.

Press the shortcut on something worth keeping

Alt Shift M remembers the page. The first capture downloads the model once — after that it is cached.

Three gestures

One verb, and two ways to be deliberate.

Remember the page

Alt Shift M

No prompt, no confirmation. The summary appears afterwards as a receipt, not before as a checkpoint.

Remember it with a note

Alt Shift N

The model can say what a page contains; it cannot say why you kept it. Opening this starts the summary, so you write the note while it runs.

Remember a passage

right-click a selection

Stored exactly as selected. You already chose those words — no model, instant, works without WebGPU.

What it reads

Articles, PDFs, and whatever you highlighted.

Chrome renders PDFs in a viewer no extension can enter, so magpie fetches and parses the file itself — up to forty pages, and it says so in the memory when it stops there.

Where it goes

Your memory layer, not ours.

Three adapters today, and adding one is a single file. Nothing is lost on the way: a capture is written to disk before any network call, so an unreachable provider or an expired key is a retry rather than lost work.

Anona Memory

POST /v1/record

Lists your spaces so you pick one rather than spell it.

Mem0

POST /v3/memories/add/

Lists the users it already holds.

Supermemory

POST /v3/documents

Keyed on the page, so re-remembering updates rather than duplicates.
